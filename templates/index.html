POST/api/copy

queue a copy job. X-API-Key header required if API_KEY is set on the server.
curl -X POST http://<host>/api/copy \
  -H 'Content-Type: application/json' \
  -H 'X-API-Key: $API_KEY' \
  -d '{
    "src":  "docker.io/library/nginx:1.27",
    "dest": "library/nginx:1.27",
    "src_user":  "optional-docker-user",
    "src_token": "optional-docker-token"
  }'
# → 202 { "id": "...", "state": "queued", ... }

GET/api/jobs

list jobs (newest first). optional ?limit=N, default 100.
curl http://<host>/api/jobs?limit=20

GET/api/jobs/<id>

single job snapshot.
curl http://<host>/api/jobs/<id>

GET/api/jobs/<id>/log

full skopeo log for one job (text/plain).
curl http://<host>/api/jobs/<id>/log

POST/api/jobs/<id>/cancel

cancel a queued/running job.
curl -X POST http://<host>/api/jobs/<id>/cancel \
  -H 'X-API-Key: $API_KEY'

POST/api/jobs/<id>/retry

re-queue a failed/cancelled job with the same parameters.
curl -X POST http://<host>/api/jobs/<id>/retry \
  -H 'X-API-Key: $API_KEY'

GET/api/registries

registry health snapshot (same data as the strip above).
curl http://<host>/api/registries

GET/health

liveness/version probe — no auth required.
curl http://<host>/health
# → { "status": "healthy", "version": "{{ version }}", "workers": N }
